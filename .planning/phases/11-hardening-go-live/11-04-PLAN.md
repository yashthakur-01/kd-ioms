# Plan 11-04: Master Data CSV Import Utilities

**Phase:** Phase 11 — Hardening, Reliability and Go-Live  
**Plan ID:** `11-04`  
**Wave:** 4 (Master Data Migration & Tooling)  
**Dependencies:** Phase 0, Phase 3  
**Responsible Developer:** `dev1`  

---

## 1. Objective

Provide production-grade, two-stage CSV import utilities (`import-salts.ts` and `import-medicines.ts`) for loading opening product catalogs and salt masters before go-live. Each utility supports `--dry-run` validation, constraint checking, phonetic duplicate detection, transactional batch loading, and structured error reporting.

### Task 2: Salt Master Import Script (`backend/src/scripts/import-salts.ts`)
- Implement script that:
  1. Accepts CSV file path as CLI argument: `npx tsx src/scripts/import-salts.ts path/to/salts.csv [--dry-run]`.
  2. Parses CSV, strips whitespace, and deduplicates rows within the file.
  3. Validates salt names (non-empty, max 255 chars).
  4. Queries existing database salts; flags exact matches (`DUPLICATE_RESOURCE`) and calculates trigram similarity (`SALT_SIMILAR_EXISTS`).
  5. In `--dry-run` mode: prints summary table of `Total Rows`, `Valid Inserts`, `Exact Duplicates Skipped`, `Similar Warnings`.
  6. In live mode: executes bulk `INSERT INTO salts (salt_name, created_at, updated_at)` inside a single transaction.

### Task 3: Medicine Master Import Script (`backend/src/scripts/import-medicines.ts`)
- Implement script that:
  1. Accepts CSV file path: `npx tsx src/scripts/import-medicines.ts path/to/medicines.csv [--dry-run]`.
  2. Parses columns: `name, company, pack_size, mrp, gst_rate, hsn_code, salts`.
  3. Validates data types with Zod schema (`mrp > 0`, `gst_rate in [0, 5, 12, 18, 28]`, non-empty strings).
  4. Resolves comma-separated salts: looks up `salt_id` from database; flags any unknown salt name with row line number.
  5. In `--dry-run` mode: displays table with validation status per row and overall error list.
  6. In live mode: inside `withTransaction`, inserts into `medicines` and `medicine_salts` junction table.

### Task 4: Add Root Package.json Scripts
- Add convenience scripts to `package.json` / `backend/package.json`:
  ```json
  "import:salts": "tsx src/scripts/import-salts.ts",
  "import:medicines": "tsx src/scripts/import-medicines.ts"
  ```

### Task 5: Unit & Integration Tests (`backend/src/scripts/__tests__/import-csv.test.ts`)
- Implement tests verifying:
  1. CSV parsing and header validation.
  2. `--dry-run` mode executes without modifying database tables.
  3. Live import successfully inserts records and creates salt linkages.
  4. Invalid CSV format or missing required salts causes clean transaction rollback.
