## 1. Objective

Implement database disaster recovery automation (`scripts/backup-db.ts`) with SHA-256 checksum verification, author a rehearsed database restore procedure, enhance service observability with connection pool telemetry on `/api/v1/health`, add a keep-warm ping client for Render free-tier hosting, and wire graceful shutdown handlers in `server.ts`.

---

## 2. Tasks & Detailed Instructions

### Task 1: Database Backup Utility (`backend/src/scripts/backup-db.ts`)
- Implement a standalone TypeScript backup script that:
  1. Resolves `DATABASE_URL` from environment.
  2. Spawns `pg_dump` (or streams database tables using SQL COPY if pg_dump binary is absent) to create a timestamped dump: `backups/kd_ioms_backup_YYYYMMDD_HHMMSS.sql`.
  3. Computes and saves a SHA-256 hash in a companion file: `backups/kd_ioms_backup_YYYYMMDD_HHMMSS.sha256`.
  4. Generates a metadata descriptor: `backups/kd_ioms_backup_YYYYMMDD_HHMMSS.meta.json` with table row counts and file byte size.
  5. Implements a retention pruning option (`--keep=7`) to remove older backups.

### Task 2: Restore Rehearsal & Verification Script (`backend/src/scripts/verify-restore.ts`)
- Implement a script that:
  1. Verifies the SHA-256 checksum of the target backup file before applying.
  2. Applies the SQL dump against a designated target database or schema.
  3. Verifies table presence, row counts, and schema migration integrity.
  4. Outputs a verification report for audit sign-off.

### Task 4: Render Keep-Warm Ping Client (`backend/src/scripts/keep-warm.ts`)
- Implement an automated lightweight HTTP client that:
  1. Pings the target backend URL `/api/v1/health` every 10 minutes (configurable via `KEEP_WARM_INTERVAL_MS`).
  2. Logs latency and responses via Pino logger.
  3. Gracefully handles network blips without crashing.

### Task 5: Graceful Shutdown Lifecycle (`backend/src/server.ts`)
- Implement signal listeners in `backend/src/server.ts`:
  ```typescript
  async function gracefulShutdown(signal: string) {
    logger.info({ signal }, 'Received shutdown signal, closing server gracefully...');
    server.close(async () => {
      logger.info('HTTP server closed, draining database pool...');
      await pool.end();
      logger.info('Database pool drained, process exiting cleanly.');
      process.exit(0);
    });
    // Force shutdown after 10s timeout
    setTimeout(() => {
      logger.error('Forced shutdown due to timeout');
      process.exit(1);
    }, 10000).unref();
  }

  process.on('SIGTERM', () => gracefulShutdown('SIGTERM'));
  process.on('SIGINT', () => gracefulShutdown('SIGINT'));
  ```
