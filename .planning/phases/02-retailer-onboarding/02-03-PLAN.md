# Plan 02-03: Admin Review Queue, Verification Dialogs & Validation

<objective>
Build the admin retailer management dashboard (`/admin/retailers`), application detail review page (`/admin/retailers/[userId]`), approval confirmation modal, and rejection dialog with preset chips, concluding with full test suite validation.
</objective>

<threat_model>
- **T-02-07 (Accidental Approval):** Admin inadvertently approves an incomplete or invalid retailer application.
  - *Mitigation:* Explicit `ConfirmDialog` summarizing Shop Name, Drug License, and GSTIN before committing `POST /retailers/:userId/approve` (per D-11).
- **T-02-08 (Vague or Missing Rejection Reason):** Admin rejects an application without actionable feedback for the retailer.
  - *Mitigation:* `RejectionModal` enforces 5–300 character textarea with live counter and provides standardized preset chips for common compliance issues (per D-10).
</threat_model>
