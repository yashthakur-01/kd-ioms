## Visuals & Layout Hierarchy

### Primary Screen Focal Points
1. **Retailer Profile Screen (`/profile`):**
   - **Focal Point:** The prominent full-width Status Card at the top of the container:
     - *PENDING:* Amber alert card with clock icon and "Check Verification Status" action button.
     - *REJECTED:* Red alert card with alert triangle icon, displaying the admin's exact rejection remarks.
     - *APPROVED:* Emerald celebration card with checkmark badge and "Browse Catalog & Order" primary CTA.
   - **Secondary Element:** The KYC inspection card (clean read-only details with quick-copy buttons when submitted, or active form when unsubmitted/rejected).
2. **Admin Retailer Queue (`/admin/retailers`):**
   - **Focal Point:** The top Status Filter Bar with active tab indicator and live badge counts (`Pending Review (N)`, `Approved`, `Rejected`, `All`).
   - **Secondary Element:** Search input and the sortable applications data table with quick "Review" action buttons.
3. **Admin Review Detail Page (`/admin/retailers/[userId]`):**
   - **Focal Point:** The sticky Bottom Action Bar featuring distinct "Approve Application" (emerald) and "Reject Application" (red) buttons.

### Accessibility & Icon Fallbacks
- All action icons (quick-copy buttons, manual refresh spinner, modal close icons) include explicit `aria-label` and visible adjacent text or tooltip fallbacks.
- Disabled navigation items in `BottomNav` display both a lock icon and tooltip / text indicator ("KYC Approval Required").
