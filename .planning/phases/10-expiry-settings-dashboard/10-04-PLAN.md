# Plan 10-04: Frontend Alerts Hub & Navigation Badge

**Phase:** Phase 10 — Expiry Alerts, Settings and Dashboard  
**Plan ID:** `10-04`  
**Wave:** 4  
**Dependencies:** Plan 10-02 (Alerts API), Phase 4 (Batch Management UI)  
**Responsible Developer:** `dev3`  

---

## 1. Objective

Build the frontend administrative alerts management center (`/alerts`) featuring a 3-way tabbed operational workflow (Near Expiry, Expired Stock, Out of Stock), inline dismissal actions, a physical disposal write-off modal (`RemoveExpiredModal`), and a persistent 60-second polling alert count badge in the admin navigation.

---

## 2. Tasks & Detailed Instructions

### Task 1: Alerts Feature Architecture (`frontend/src/features/alerts/`)
1. Create `frontend/src/features/alerts/types.ts`:
   - Interfaces for `NearExpiryAlertItem`, `ExpiredStockItem`, `OutOfStockMedicineItem`, and API response envelopes.
2. Create `frontend/src/features/alerts/api.ts`:
   - `fetchNearExpiryAlerts(params: { page?: number; pageSize?: number; search?: string })`
   - `fetchExpiredStockAlerts(params: { page?: number; pageSize?: number; search?: string })`
   - `dismissNearExpiryAlert(batchId: number)` -> `POST /api/v1/alerts/near-expiry/:batchId/dismiss`
   - `removeExpiredBatch(batchId: number, data?: { reason?: string })` -> `POST /api/v1/batches/:batchId/remove-expired`
3. Create `frontend/src/features/alerts/hooks.ts`:
   - `useNearExpiryAlerts(params)`
   - `useExpiredStockAlerts(params)`
   - `useDismissNearExpiryMutation()`: On success, invalidates `['alerts', 'near-expiry']` and `['dashboard', 'summary']`.
   - `useRemoveExpiredBatchMutation()`: On success, invalidates `['alerts', 'expired']`, `['batches']`, and `['dashboard', 'summary']`.
   - `useAlertsBadgeCount()`: Fetches near-expiry and expired totals with `refetchInterval: 60_000` (60 seconds).

### Task 2: Modals & Row Components (`frontend/src/features/alerts/components/`)
1. Create `frontend/src/features/alerts/components/RemoveExpiredModal.tsx`:
   - Controlled dialog component receiving `batch: ExpiredStockItem | null`, `isOpen`, `onClose`.
   - Clear warning callout: "This action will permanently write off all {batch.quantityOnHand} units from inventory and record an EXPIRY_WRITEOFF ledger audit entry."
   - Optional reason input (`textarea`, max 300 chars, placeholder: "e.g. Expired batch disposed in bio-waste").
   - Action buttons: "Cancel" and "Confirm Removal & Write-Off" (with loading spinner).
2. Create `frontend/src/features/alerts/components/NearExpiryTable.tsx`:
   - Columns: Medicine Name, Batch No, Expiry Date, Days Remaining (color-coded badge: red <= 30d, amber <= 60d, blue > 60d), Quantity On Hand, Actions.
   - Row Actions:
     - "Keep (Dismiss)" button: tooltipped, triggers dismiss mutation with confirmation toast.
     - "Adjust Stock" link/button: navigates to `/batches/[batchId]` or opens adjustment dialog.
3. Create `frontend/src/features/alerts/components/ExpiredStockTable.tsx`:
   - Columns: Medicine Name, Batch No, Expiry Date, Days Expired (destructive badge), Unsold Quantity, Actions.
   - Action: "Remove Expired Stock" button triggering `RemoveExpiredModal`.
4. Create `frontend/src/features/alerts/components/OutOfStockTable.tsx`:
   - Lists medicines with 0 available stock.
   - Action: "Receive Stock" button linking directly to `/stock/inward?medicineId=...`.

### Task 3: Alerts Page & Navigation Badge Integration
1. Create `frontend/src/app/(admin)/alerts/page.tsx`:
   - `PageHeader` with title "Inventory & Expiry Alerts" and operational subtitle.
   - Tab strip:
     - "Near Expiry" (with count badge)
     - "Expired Stock" (with count badge)
     - "Out of Stock" (with count badge)
   - Synchronized with query parameter `?tab=near-expiry|expired|out-of-stock`.
   - Search bar and pagination controls.
2. Update Admin Navigation / Sidebar (`frontend/src/components/layout/`):
   - Hook into `useAlertsBadgeCount()`.
   - Display dynamic badge indicator next to "Alerts" navigation link with total actionable alerts.

### Task 4: Frontend Test Suite (`frontend/src/features/alerts/__tests__/alerts.test.tsx`)
1. Create component unit tests:
   - Render `NearExpiryTable` and verify "Keep (Dismiss)" button calls dismiss mutation.
   - Render `ExpiredStockTable` and verify clicking "Remove" opens `RemoveExpiredModal`.
   - In `RemoveExpiredModal`, verify submitting calls `removeExpiredBatch` with user-entered reason.
   - Verify tab navigation changes view.
